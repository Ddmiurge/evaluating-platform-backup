## 3. 现在能做什么

**企业**

- 连接被测目标：OpenAI 兼容 LLM，或自定义 HTTP 智能体（模板 + 响应路径，探活与真实调用同形）；
- 对话式评测：描述需求 → 计划卡（插件轴 / 策略轴分开展示，可 `×` 移除、可追加策略）→ 确认 → 报告卡 + PDF；
- 自选评测：直接选插件/策略，插件/策略下拉含「专家发布」分组；
- 报告：逐条攻击载荷与目标回答、判定理由、指标（攻击成功 / 攻击失败 / 未取得回答分开计数）、评分依据行。

**专家**

- 样本 / 模板 / 组合攻击管理；Skill 与 MCP 服务；
- 自定义**插件**与**策略**发布（插件仅 YAML；策略有文本/代码两形态，代码包受开关 `MACLAW_STRATEGY_CODE_PACKAGES` 控制，默认关闭），支持对同一包「重新发布」（按 id 更新，不新增）；策略发布页支持**从文件上传**（`.js/.mjs` ≤256KB、`.yaml/.yml` ≤128KB，客户端预检 + 纯文本回显，P24/45 号已验）；
- 平台能力目录浏览（P23）：发布页主体即分组目录——内置插件按 promptfoo 原生类别分组、内置策略平组、全体专家已发布包并入「专家发布包」组，本账号发布的行特殊标注并保留重新发布/下架操作；**不显示发布者是谁**；
- Hub 发布与 Skill 分发。

**管理员**

- 模型配置（平台默认 + 账号覆盖）；账号/租户；健康摘要；
- 资源治理：自定义插件**与**策略的启停 / 归档，即时生效。

**引擎执行语义（都已上机验证）**

- 只走 promptfoo 原生生成（Plan A 已删除）；
- 逐插件 rubric 判分；判定口径文案区分「谁判每条」与「谁汇总」；
- 策略包装不额外跑一遍无策略对照组；探针数 = `num_tests × 策略个数`；
- 目标调用失败分类为可读短语，不泄漏内网地址/引擎路径/堆栈；
- 自定义插件/策略经 `pf_plugin:` / `pf_strategy:` 引用，两条入口（向导、计划卡）同一解析器。
