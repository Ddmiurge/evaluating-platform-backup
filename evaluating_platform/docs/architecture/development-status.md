## 3. 现在能做什么

**企业**

- 连接被测目标：OpenAI 兼容 LLM，或自定义 HTTP 智能体（模板 + 响应路径，探活与真实调用同形）；
- 对话式评测：描述需求 → 计划卡（插件轴 / 策略轴分开展示，可 `×` 移除、可追加策略）→ 确认 → 报告卡 + PDF；
- 自选评测：直接选插件/策略，插件/策略下拉含「专家发布」分组；
- 报告：逐条攻击载荷与目标回答、判定理由、指标（攻击成功 / 攻击失败 / 未取得回答分开计数）、评分依据行。

**专家**

- 样本 / 模板 / 组合攻击管理；Skill 与 MCP 服务；
- 自定义**插件**与**策略**发布（插件仅 YAML；策略有文本/代码两形态，代码包受开关 `MACLAW_STRATEGY_CODE_PACKAGES` 控制，默认关闭），支持对同一包「重新发布」（按 id 更新，不新增）；策略发布页支持**从文件上传**（`.js/.mjs` ≤256KB、`.yaml/.yml` ≤128KB，客户端预检 + 纯文本回显，P24/45 号已验）；
- 平台能力目录浏览（P23）：发布页主体即分组目录——内置插件按 promptfoo 原生类别分组、内置策略平组、全体专家已发布包并入「专家发布包」组，本账号发布的行特殊标注并保留重新发布/下架操作；**不显示发布者是谁**；
- Hub 发布与 Skill 分发。

**管理员**

- 模型配置（平台默认 + 账号覆盖）；账号/租户；健康摘要；
- 资源治理：自定义插件**与**策略的启停 / 归档，即时生效。

**引擎执行语义（都已上机验证）**

- 只走 promptfoo 原生生成（Plan A 已删除）；
- 逐插件 rubric 判分；判定口径文案区分「谁判每条」与「谁汇总」；
- 策略包装不额外跑一遍无策略对照组；探针数 = `num_tests × 策略个数`；
- 目标调用失败分类为可读短语，不泄漏内网地址/引擎路径/堆栈；
- 自定义插件/策略经 `pf_plugin:` / `pf_strategy:` 引用，两条入口（向导、计划卡）同一解析器。

## 5. 下一步（建议顺序）

1. **48 号剩两个动作**：① `.env` 落盘 `MACLAW_STRATEGY_CODE_PACKAGES=1`（现仍靠 `sudo env` 临时传，重建即回 0——47/48 两轮点名的同类陷阱；一行文件写入，待主理人点头）；② 新 provider（DeepSeek 官方直连）下补跑代码包端到端：`p47file` 向导 + 确认两条、`p22hang` 失败原因一条（约 3 run）；
1b. **部署备忘（48 号 §5 排查成果）**：`.env`/`configs/*.yaml` 的 `LLM_BASE_URL/LLM_MODEL/LLM_API_KEY` 是**无消费点的遗留占位**——真实的生成/判定模型只认管理员门户配置（`maclaw_model_defaults` + 账号级 config）；且**判定与生成共用同一套 key**，欠费/换供应商会同时打两条链路（mimo 402 那次即整链全挂）。排障别从 `LLM_*` 入手；
2. **46 / 47 号已闭环**（记录备查，不再作为待办）：DNS 由仓库 compose 承担（不带 override 重建、端到端 2/2 成功）；`error_brief` 进 run DTO 且进度/SSE 禁令未扩散；代码包两条入口端到端真跑（`custom:code:*`、报告无 `file://`）；P26a 双条件闸 409 不落行、默认关 = P25 逐字节。
3. **租户隔离 G-1~G-3（P26b/c/d）**：设计稿 `tenant-isolation-g1-g3.md`——P26a 已落地并上机（47 号）；未做的是 P26b 生成 key 按租户、P26c 实例级 token 供给 + 专属实例 compose 白名单、P26d 跨租户判据。**生产开闸的资格线**：这三项没做之前「共享部署不放代码包」的结论不变，47 号的开闸只适用于 ai02 这台验证机；
4. **部署脚本自检**：`df -h /var` 低于阈值即停；部署后探测引擎能否解析生成模型域名；**并把「新 env 必须 compose 透传」做成自动检查**（比对 `pkg/config` 的 `BindEnv` 键与 compose 渲染出的容器环境，缺失即停——46/47 两轮都是这条）；
5. **混合场景上机验证**：用确定性靶机桩（前 N 次正常、之后拒连）补上唯一未上机的分支；
6. 目标侧 300 秒队列超时（Dify）—— 运维/靶机配置；
7. 体验与体积：报告卡摘要、PDF 字体子集化；复验遗留的临时代码策略包（`p22lazy`/`p22hang`）可按需下架（`p47file`、`p18upper` 留作后续回归固定素材）。
