## 1. 判据 1 · `.js/.mjs`（≤256KB）或 `.yaml/.yml`（≤128KB）

在 node 里 **import 前端真实模块**（不是复刻规则）执行：

```
acceptForForm('js')            = '.js,.mjs'        ✅
acceptForForm('yaml')          = '.yaml,.yml'      ✅
PACKAGE_UPLOAD_LIMITS = { js: 262144, yaml: 131072 }  ✅（256KB / 128KB）
```

页面 `<Upload accept={acceptForForm(formKind)}>` 用的是同一个函数，提示语随形态切换：代码形态「支持 .js / .mjs，UTF-8，≤ 256 KB」，文本形态「支持 .yaml / .yml，UTF-8，≤ 128 KB」。

## 2. 判据 2 · 客户端预检（扩展名 / 空文 / 含空字节 / UTF-8 上限）

`validatePackageFile(name, text, kind)` 实测 **30 条断言全通过**：

| 场景 | 结果 |
|---|---|
| `.yaml` / `.yml` / `.js` / `.mjs` 合法内容 | `{ok:true}` |
| 错扩展名（`s.txt`） | 拒，文案给两种形态的扩展名 |
| **另一形态**的扩展名（yaml 形态选了 `.js`，反向同理） | 拒，且明确指出「是另一种形态的扩展名」并让切换形态选择器 |
| 空内容 `''` | 拒（`内容是空的`） |
| 纯空白 `'  \n\t \n'` | 拒（同样按空文处理） |
| 含空字节 `'ab\u0000cd'` | 拒（`不像 UTF-8 文本（含空字节）`） |
| 带 BOM 的 YAML | `stripBom` 后放行；只有 BOM 的文件剥后为空 → 拒 |
| 回显 | 通过后 `form.setFieldValue('payload', text)`，并显示「已载入 xxx（N KB），可直接编辑后发布」 |

线上产物核对（`dist/assets/index-CKD7bS_O.js`）：`从文件上传`、`支持 .js / .mjs`、`支持 .yaml / .yml`、`已载入`、`.js,.mjs`、`262144` 各命中 1 处。
