## 0. 三个阻断性根因（都不是阶段一引入的）

实测发现的 Plan C 代码路径既有问题，按清单 §0-2 的约定**如实归类为上游/既有问题**：

### 根因 A · promptfoo 库模式不迁移 SQLite schema（可运维绕过）

- **现象**：任何 Plan C run 在生成前即失败，引擎侧报 `LibSQL/DrizzleQueryError: no such table: eval_results`。
- **定位**：promptfoo 的 `checkRedteamProbeLimit()` 在 `redteam.run()` 内部先查 `eval_results` 表；库模式（非 CLI）不会自动执行 drizzle 迁移。**引擎生产代码没有预迁移**，但引擎自己的测试夹具 `u9PromptfooHome.ts` 有——测试与生产契约漂移。
- **绕过（本次实测采用的运维手段，非代码修复）**：run 前在容器内执行一次 drizzle 迁移：

  ```bash
  docker exec -w /app ep_promptfoo_engine node --input-type=module -e "
  const m = await import('file:///app/node_modules/drizzle-orm/libsql/migrator.js');
  const { createClient } = await import('file:///app/node_modules/@libsql/client/lib-esm/node.js');
  const { drizzle } = await import('file:///app/node_modules/drizzle-orm/libsql/node/index.js');
  const c = createClient({ url: 'file:/home/node/.promptfoo/promptfoo.db' });
  await m.migrate(drizzle(c), { migrationsFolder: '/app/node_modules/promptfoo/dist/drizzle' });
  c.close(); console.log('migrated');"
  ```

  注：清理钩子每次 run 终态都会删掉 db 文件，所以**每个 run 前都要预迁移一次**。
- **修复建议**（阶段二）：引擎在 native 路径初始化时执行同样的迁移。

### 根因 B · `jailbreak` 策略被内部升级为 `jailbreak:meta`，需要远程生成（策略级阻断）

- **现象**：选 `jailbreak` 策略的 run 在 scan 阶段失败：`jailbreak:meta strategy requires remote generation`。
- **定位**：promptfoo 0.123.0 将 `jailbreak` 策略实现为 iterative:meta 家族，其实现要求 promptfoo 云端远程生成；而平台四个 fail-closed 环境变量已按 U10 边界禁用远程生成 → fail-closed 正确触发，run 失败。
- **定性**：这是 **fail-closed 按设计工作**，不是故障；但它使 `jailbreak` 策略在 Plan C 下永久不可用（除非阶段二做本地化实现或映射到其它本地策略）。

### 根因 C · `prompt-injection` 不是 promptfoo 合法插件 id（配置校验阻断）

- **现象**：含 `prompt-injection` 插件的 run 在 800ms 内失败：`Invalid plugin id "prompt-injection". Custom plugins must start with file:// or use a built-in plugin`（zod 校验，redteam.plugins[3]）。
- **定位**：`prompt-injection` 是平台自造目录 id，promptfoo 0.123.0 没有这个插件 id（其注入攻击在 `direct-agent-harm`/`shell-injection`/`sql-injection` 等具体插件里）。
- **波及**：凡是平台目录里把 `prompt-injection` 当可选插件下发到引擎的 run 都会整体失败——**不是降级，是整 run 失败**。
- **附注（目录失真）**：U6 闸门的错误提示文案声称「当前环境可完整评测的插件（共 29 个）例如：harmful、jailbreak、pii、**prompt-injection**…」——该目录与 promptfoo 实际接受面不一致，需在阶段二校正。

| 平台插件 id | promptfoo 合法性 | 平台策略 id | 映射结果 | 合法性 |
|---|---|---|---|---|
| prompt-extraction | ✅ VALID | crescendo | → crescendo | ✅ |
| pii | ✅ VALID | goat | → goat | ✅ |
| pii:social | ✅ VALID | hydra | → jailbreak:hydra | ✅（见根因B） |

12 个 `PLAN_A_ONLY` 维度（direct/role-play/encoding/multi-turn/assumed-knowledge/few-shot/many-shot/translate/otherEncodings/simba/retry/mathPrompt）经离线复现 `nativeStrategyMapping` **全部为丢弃语义**，映射表本身无误。
