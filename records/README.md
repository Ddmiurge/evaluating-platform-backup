## reports/

生成物（PDF 报告、markdown 报告导出）放在 `reports/`，与验证记录分开：

| 文件 | 来源 |
|---|---|
| `p8_rpt.md` | 早期评测报告导出（markdown） |
| `maclaw-report-redteam_report_241665bb7e1cd6cecd1cef8f.pdf` | P7 轮次报告（评审用） |
| `maclaw-report-redteam_report_5c42d28769db8a68162626b9.pdf` | P8 轮次报告（评审用） |

PDF 是二进制、可由评测重跑再生，因此**不入库**（见 `reports/.gitignore`）；
markdown 导出体积小，随仓库保存。

> 写记录的纪律：观测按原样记录，**不记得「通过」的那些不算通过**；
> 事后发现当时的判断有误时，在文末追加更正段，而不改动原文（例：`25-…` 的 §6）。
