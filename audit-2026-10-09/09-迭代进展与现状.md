## 6.1 环境事实（2026-10-10 新增）

本机（macOS arm64）原**无 Go 工具链**，已按如下方式安装，供后续批次复用：

```bash
curl -fsSL -o go.tar.gz https://go.dev/dl/go1.25.5.darwin-arm64.tar.gz
tar -xzf go.tar.gz          # 解压到 /Users/huangqixu/sdk/
/Users/huangqixu/sdk/go/bin/go version   # go1.25.5 darwin/arm64
```

- **不要用 `brew install go`**：沙箱不允许写 `/opt/homebrew`（报 `index.lock` / `Operation not permitted`）。
- **调用 Go 时用绝对路径** `/Users/huangqixu/sdk/go/bin/go`；写 `export PATH=...:$PATH` 会触发沙箱 `connection refused: /dev/null`。
- 本机**无 Docker**，`compose` 验证以 CI 为准（`08` §5 纪律第 3 条）。
